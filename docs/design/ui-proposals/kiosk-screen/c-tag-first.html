이름표가 주인공

아이가 받아 갈 이름표를 화면에 크게 보여 줍니다. 인식되면 빈 이름표에 이름이 채워지고, 그 이름표를 누르면 출력됩니다. 닮은 형제는 이름표 두 장 중 자기 것을 고르고, 등록할 때는 이름표의 네 모서리가 채워집니다. 서버 앱 첫 화면은 오늘 출력된 이름표가 부서별로 쌓이는 출석 보드입니다.

보이는 그대로 출력화면의 이름표가 곧 출력물. 잘못된 이름을 뽑기 전에 알아챔
고르기는 이름표로후보, 본인 확인, 이름표만 받기 모두 이름표를 보고 결정
