## 설치 파일

빌드한 PC의 저장소 기준 경로입니다. 다른 PC에서는 `cd android && ./gradlew :kiosk-app:assembleDebug :server-app:assembleDebug`로 다시 만듭니다.

| 앱 | 파일 | 패키지 |
|---|---|---|
| 키오스크 (Faith ID) | `android/kiosk-app/build/outputs/apk/debug/faith_id.apk` (약 253MB, 인식 모델 포함) | `com.example.facetestbed` |
| DB 서버 (Faith DB Server) | `android/server-app/build/outputs/apk/debug/faith_db.apk` (약 20MB) | `com.example.facedbserver` |

- 둘 다 **디버그 빌드**입니다. 시험용 기능이 들어 있으므로, 교회 밖으로 배포할 때는 서명한 릴리스 빌드로 다시 만드세요.
- 설치: `adb install -r <파일>` 또는 태블릿에 파일을 복사해 실행합니다.
- 실제 교인 데이터와 얼굴 데이터는 APK와 저장소에 들어 있지 않습니다.

## DB 서버

| 항목 | 값 |
|---|---|
| 주소 | `http://<서버 태블릿 IP>:18080`. 시험 때는 `192.168.45.107`이었고, 공유기가 IP를 정하므로 바뀔 수 있습니다. 서버 앱 현황 화면에서 확인합니다. |
| 관리자 ID | `admin` |
| 관리자 비밀번호 | 처음 값은 `1234`이며, 첫 로그인 때 바꾸도록 요구됩니다. 지금 비밀번호는 담당자에게 확인하세요. 서버는 해시만 저장하므로 파일에서 읽을 수 없습니다. |
| 데이터 폴더 | 태블릿 `/sdcard/faceDB`: 얼굴 데이터 `face_meta.db`, 출석 `attendance.db`, 내보낸 `face_db.csv`와 날짜별 `attendance_YYYY-MM-DD.csv` |
| 자동 시작 | 꺼짐. 태블릿을 다시 켜면 서버 앱을 열고 시작을 눌러야 합니다. |

### 백업에서 복원

1. 서버 앱에서 서버를 중지합니다.
2. `/sdcard/faceDB`의 DB 파일을 백업본으로 바꾸고, 같은 이름의 `-wal`, `-shm` 파일을 지웁니다.
3. 서버를 시작합니다.
4. 명단 → **DB 다시 읽기**를 누릅니다. 연결된 키오스크가 1초 안에 새 DB를 내려받습니다.

시험 전에 받아 둔 백업(80명)은 시험 PC의 `local-data/tablet-backup/faceDB-20261025-before-perf`에 있습니다. 이 폴더는 git에 올라가지 않습니다.

## 키오스크

- 키오스크 자체 비밀번호는 없습니다.
- 연결:
  1. 키오스크 설정에 서버 주소를 입력합니다.
  2. 서버 앱에서 그 키오스크를 승인합니다.
- 서버와 같은 태블릿에서 쓸 때: 키오스크를 열면 "서버와 동기화를 유지하고 있습니다" 알림이 뜹니다. 이 알림이 있으면 서버 앱을 앞에 띄워 두어도 동기화와 출석 전송이 계속됩니다.
