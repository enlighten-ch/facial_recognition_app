따뜻한 안내자 화면 적용

UI 연구에서 고른 제안 B v9(따뜻한 안내자)를 키오스크와 서버 앱에 적용하고, 안내 캐릭터 빛이의 동작을 더했습니다. PC 에뮬레이터와 태블릿 두 대에서 시험했고, 사용 안내서를 새 화면으로 바꿨습니다.

요약

145단위 시험 통과 (실패 0, 건너뜀 1)
11 / 11키오스크 종단 시험: 에뮬레이터, 태블릿 1
17 / 17화면 따라가기 시험: 태블릿 2
266 / 266키오스크 6대 모의 시험의 출석 건수 일치

모든 변경은 improve/stability-attendance 브랜치에 올렸고, 작업은 이슈 #23에 정리했습니다. 두 태블릿에 최신 앱(디버그 빌드)을 설치했습니다. 태블릿 1이 잠겨 있어 서버를 다시 켜지 못했습니다(아래 남은 일).

바뀐 점

키오스크 (Faith ID)

  • 카메라가 화면 전체에 나오고, 빛이가 위쪽 말풍선에서 안내합니다. 버튼은 아래쪽에 반투명하게 떠 있습니다.
  • 안내 대상: 어린이(반말, 별·꽃가루)와 어른(같은 빛이, 정중한 말투). 설정 › 일반에서 고릅니다.
  • 얼굴 등록 12가지 동작: 왼쪽·오른쪽·위·아래 방향마다 보통·큰·작은 동그라미에 얼굴을 맞춥니다. 큰 동그라미는 얼굴이 실제로 커져야(가까이), 작은 동그라미는 작아져야(멀리) 받아들입니다.
  • 바라볼 쪽에 별, 같은 높이에 방향과 거리를 시범 보이는 3D 머리, 12개를 다 모으면 축하 화면.
  • 이름 입력: 키오스크가 가진 명단에서 부서·학년 칩을 만들어 고르게 합니다(직접 입력도 가능). 이름표 카드 화면, 등록 완료 안내.
  • 빛이의 동작: 몇 초마다 깜빡이고, 상황마다 점프·갸우뚱·끄덕 같은 동작을 합니다. 상황과 동작의 표는 코드 한 곳(GuideGestures)에서 관리합니다.
  • 설정: 오른쪽 위 거의 보이지 않는 톱니를 1.2초 길게 눌러야 열립니다. 안내 문구 탭을 따로 두어 빛이의 말을 어린이·어른별로 바꿀 수 있습니다.
  • 호환: 공장 기본값 그대로인 얼굴 동그라미는 새 화면에 맞게 조금 작고 낮아집니다. 직접 맞춘 값은 그대로 두고, 등록할 때만 화면에 맞도록 같은 비율로 줄입니다.

서버 앱 (Faith DB Server)

  • 탭: 오늘의 순서 / 명단 / 출석 / 키오스크. 오늘의 순서는 서버 켜기, 키오스크 허락, 명단, 출석부 저장을 차례로 보여 주고 부서별 출석 막대를 함께 보여 줍니다.
  • 명단과 출석은 표입니다. 머리글을 누르면 정렬, 부서 필터와 검색, 명단은 줄을 눌러 그 자리에서 고치기, 출석은 온 사람/아직 안 온 사람으로 나눠 보기.
  • 개발자 화면: 상태, 모든 서버 설정과 config.yaml(비밀번호 해시는 가림), 데이터 폴더의 파일과 관리 작업, 키오스크 표, 종류별로 거르고 찾는 전체 로그.
  • 이전 화면에서 하던 일(CSV 반영·저장, DB 다시 읽기, 기간 내보내기, 비밀번호 변경, 로그아웃, 서버 종료)은 모두 그대로 할 수 있습니다.

문서와 도구

  • 사용 안내서를 새 화면과 스크린샷으로 다시 썼습니다: 사용 안내서 (docs/user-guide/).
  • UI 시안은 v1~v9를 모두 남겼습니다(docs/design/ui-proposals/registration/).
  • tools/ui_walkthrough_kiosk.sh: 가상 얼굴로 키오스크 화면을 처음부터 끝까지 따라가며 문구를 확인합니다. 실제 카메라가 있는 태블릿에서는 스크린샷을 흐리게 저장하고, 실제 프린터가 있으면 출력을 건너뜁니다.
  • 종단 시험 스크립트를 새 화면에 맞추고, 데이터 폴더 지정(DATA_DIR), 다른 앱의 오류 창 닫기, 키보드가 있을 때만 뒤로 가기를 더했습니다.

시험 중 찾아 고친 문제

  • 큰 동그라미 단계에서 별이 동그라미에 붙거나 겹침 → 별 크기에 맞춰 간격을 둠.
  • 직접 크게 맞춘 동그라미(태블릿 2)에서 위쪽 별이 말풍선에 가려짐 → 등록 때 세 동그라미를 같은 비율로 줄여 화면에 맞춤. 카메라 분석도 같은 크기를 씀.
  • 태블릿에서 키보드가 “다 됐어요” 버튼을 가림 → 키보드 높이만큼 비켜 주고, 이름 뒤 완료·칩 선택 때 키보드를 닫고, 마지막 칸 완료로 저장.
  • 저장·출력 뒤 다음 화면에 키보드가 남음 → 이름 입력을 벗어나면 닫음.
  • 입력한 부서가 칩과 같아지면 키보드가 닫힘 → 사람이 누른 칩만 키보드를 닫음.
  • 서버 오늘의 순서: 서버가 꺼져도 “모두 연결됨”으로 보임, 평일에도 “주일 아침” 문구, 부서 인원 숫자가 두 줄로 나뉨 → 고침.
  • 서버 개발자 화면: 실행 중에도 시작 버튼이 보임, 긴 파일 목록 아래로 관리 버튼이 밀림, 대기 중 기기 거절 창이 “연결 끊기”로 보임 → 고침.
  • 시험 도구: 화면 읽기에 실패하면 이전 화면을 돌려주던 문제 → 실패를 그대로 알림.

남은 일과 확인할 것

태블릿 1: 잠금 해제 후 서버 다시 켜기, 충전앱을 업데이트하며 서버가 멈췄고, 태블릿이 PIN으로 잠겨 있어 로그인하지 못했습니다. 서버 데이터 폴더는 실제 폴더(/sdcard/faceDB, 80명)로 되돌려 두었으니 로그인 후 서버 시작만 누르면 됩니다. 배터리가 7%였습니다.
키오스크가 실제 명단을 다시 받는지 확인시험 동안 두 키오스크는 시험 명단을 받았습니다. 서버를 켜면 새 명단으로 판단해 실제 명단 전체를 다시 받습니다. 태블릿 2에 보내지 않은 변경·출석은 0건임을 확인했습니다.
자동 보정 사진 2장태블릿 2가 시험 전에 모아 둔 자동 보정 사진 2장(한 사람)이 시험 서버로 보내졌습니다. 실제 명단에는 들어가지 않았고, 평소처럼 인식될 때 다시 모입니다.
태블릿 1의 오래된 모의 키오스크 약 60대이전 성능 시험에서 만든 “Sim perf-…” 키오스크가 허락된 채 남아 있어 오늘의 순서에 “키오스크 63대 중 1대 연결됨”으로 보입니다. 원하시면 정리하겠습니다.
Samsung 키보드 오류 창두 태블릿 모두 키보드를 열면 “스마트 추천이 계속 중단됨” 창이 뜹니다(Samsung 시스템 앱 오류). 앱과 상관없이 앱 닫기로 넘어가면 되지만, Samsung 앱 업데이트나 스마트 추천 끄기를 권합니다.
서버 태블릿 절전배터리가 부족한 채 화면이 꺼지면 키오스크가 서버에 닿지 못하는 일이 있었습니다(#24). 서버 태블릿은 충전기에 꽂아 두세요. 원인 확인은 이어서 하겠습니다.
