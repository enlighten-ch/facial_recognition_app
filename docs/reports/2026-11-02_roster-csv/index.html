명단·CSV 개선 보고서

서버 앱의 명단을 face_db.csv와 맞물려 움직이게 했습니다. CSV를 고치면 서버를 다시 시작할 때 반영되고, 명단에서 칸과 열 이름을 길게 눌러 바로 고칠 수 있으며, 바뀐 내용은 CSV·키오스크·출석부에 함께 나타납니다. 지우는 일에는 안전장치와 백업을 붙였습니다.

요약

CSV ↔ DB서버 시작 때 읽고, 고친 칸만 반영
길게 누르기칸 값 고치기 · 열 이름 바꾸기 · 열 숨기기
분류 3곳현황 · 명단 · 출석을 아무 열로
백업매일 1번 + CSV 반영·되돌리기 전
  • CSV는 이름을 성(family_name)과 이름(given_name) 두 열로 씁니다. 화면과 이름표가 둘 중 원하는 쪽을 골라 쓸 수 있습니다.
  • 열 이름을 바꾸면(예: 부서 → 반) 내용은 그대로 두고 이름만 바뀝니다. 명단 머리글, CSV 머리글, 키오스크 입력 칸, 출석부 머리글이 함께 바뀝니다.
  • CSV에서 줄을 지우면 그 사람은 DB에서도 지워집니다. 파일이 없거나 비었거나 한꺼번에 많이 빠지면 지우지 않습니다.
  • 태블릿(Galaxy Tab S7+, 실제 명단 18명)에서 사람 정보를 바꾸지 않는 방법으로 모두 확인했고, 끝난 뒤 원래 상태로 돌려놓았습니다.

CSV 반영

서버는 face_db.csv를 계속 들여다보지 않습니다. 앱을 열거나 서버를 시작할 때 한 번 읽고, 기다리기 싫으면 개발자 화면의 ‘CSV 지금 반영’을 누릅니다.

CSV에서 한 일서버가 하는 일
칸 값을 바꿈그 사람의 그 값만 바꿈
성 · 이름 칸을 바꿈이름 전체(성+이름)를 다시 만들고 나뉘는 자리를 기억
머리글 이름을 바꿈 (값은 그대로)열 이름만 바꿈. 열을 옮기거나 새 열을 같이 넣어도 값이 같으면 이름 바꾸기로 봄
새 열을 더함그 열을 더함 (값이 있는 사람만)
열을 지움그 열을 지움. 성 · 이름 열은 지워도 무시 (실수로 모두의 이름이 바뀌지 않게)
줄을 지움그 사람을 지움 (아래 ‘삭제와 백업’의 안전장치 적용)
명단에 없는 줄을 더함얼굴이 없어 사람을 만들 수 없음. 로그와 결과 창에 알림
  • 줄은 숨은 열 person_key로 사람과 맞춥니다. 그 칸이 망가지면 person_idx 번호로 맞춥니다.
  • 한국어 엑셀의 ‘CSV’ 저장(CP949)과 ‘CSV UTF-8’ 저장을 모두 읽습니다.
  • ‘CSV 편집 열기’ 버튼(명단 탭, 개발자 화면)은 태블릿의 문서 앱으로 파일을 엽니다. 테스트 태블릿에서는 Hancom Office Viewer, Microsoft 365, Polaris Office가 나왔습니다. 돌아오면 바뀐 것을 알아채고 ‘지금 반영할까요?’를 묻습니다.

열 이름과 칸 고치기

  • 머리글을 길게 누르기: ‘열 이름 바꾸기’ 창이 뜹니다. 비우면 기본 설정값(부서, 학년 · 나이 등)으로 돌아갑니다. ‘열 숨기기’도 여기서 합니다.
  • 칸을 길게 누르기: 그 사람의 그 칸 하나만 고칩니다. 저장하면 CSV에 바로 쓰이고 키오스크에 바로 알립니다.
  • 열 이름은 명단 DB에 함께 저장되어 백업·되돌리기에 포함되고, 키오스크는 명단을 받을 때 같이 받아 등록 화면의 입력 칸 이름으로 씁니다.
  • 개발자 화면 › 설정 › 명단 열에서 모든 열의 이름과 보이기를 한 번에 바꿀 수 있습니다.
키오스크 등록 화면

열 이름은 등록 화면에 반영됩니다(성, 이름, 부서, 학년 칸의 이름). 부서·학년 선택 버튼은 명단에 있는 값으로 만들어서 CSV에서 바꾼 값도 나타납니다. CSV에 새로 더한 열(예: 메모)은 등록 화면에 입력 칸이 생기지 않습니다.

성과 이름

  • 명단과 출석 탭은 이름을 성 (띄우고) 이름으로 보여 줍니다(예: 김 하은). 성을 따로 받기 전에 등록된 두 글자 이름처럼 나눌 수 없는 이름은 그대로 보입니다.
  • 줄을 누르면 고치는 칸이 성과 이름으로 나뉘어 열리고, 이름을 길게 눌러도 성·이름 두 칸으로 고칩니다. 성을 비우면 이름 칸이 전체 이름이 됩니다.
  • 짐작으로 나눈 성을 그대로 두고 저장하면 따로 저장하지 않습니다(명단이 쓸데없이 바뀌지 않게). 다른 칸 하나만 고칠 때도 이름은 건드리지 않습니다.
  • 첫 탭 이름을 ‘오늘의 순서’에서 현황으로 바꿨습니다. 주일이 아닌 날의 제목도 ‘오늘 현황’입니다.

분류 선택

현황 탭의 출석 현황, 명단의 분류 버튼, 출석 탭의 요약과 표를 부서뿐 아니라 이름을 뺀 아무 CSV 열(학년, 반, 메모 등)로 나눌 수 있습니다. 각 탭의 ‘분류: 부서 ▾’를 눌러 고르고, 고른 값은 config.yaml에 저장되어 앱을 다시 열어도 그대로입니다. 고른 열이 CSV에서 사라지면 부서로 돌아갑니다.

삭제와 백업

상황결과
CSV 파일이 없어짐아무도 지우지 않고 지금 명단으로 CSV를 새로 만듦
CSV에 줄이 하나도 없음아무도 지우지 않음 (에뮬레이터에서 321명 모두 보존 확인)
한꺼번에 10명 넘게, 그리고 30% 넘게 빠짐지우지 않고 다른 수정만 반영, 경고 표시
엑셀이 열려 있는 동안 키오스크에서 새로 등록그 사람은 지워지지 않음 (예전 사본에서 왔는지 찾아 비교)
  • 얼굴 DB 백업은 데이터 폴더의 backups에 쌓입니다. 하루 한 번(14개까지), 그리고 CSV 반영 전·되돌리기 전(20개까지).
  • 개발자 화면 › 데이터 › DB 백업에서 ‘되돌리기’를 누르면 그때의 명단·얼굴 사진·열 이름으로 돌아가고, 모든 키오스크가 명단을 새로 받습니다. 출석 기록은 그대로입니다. 지금 상태는 먼저 백업합니다.

출석부

태블릿의 오늘 출석부(attendance_2026-11-02.csv)를 열어 보니 17시 35분에 쓴 뒤 그대로여서, 그 뒤 명단에서 고친 부서 값(3빈 → 3반) 하나가 빠져 있었습니다. 지금은 명단이 바뀌면(사람, 값, 열 이름) 오늘 출석부를 바로 다시 쓰고, 머리글도 열 이름을 따릅니다. 지난 날짜의 출석부는 그날 그대로 둡니다.

고친 뒤 다시 열어 확인: 18줄 모두 지금 명단과 같고, 출석 1명, 머리글은 바꾼 열 이름을 따랐습니다.

제한과 남은 일

  • 예전 CSV 파일을 통째로 다시 넣으면, 서버가 예전에 쓴 사본과 똑같은 경우 ‘고친 것 없음’으로 봅니다(엑셀이 열어 둔 파일을 그대로 저장한 경우와 구별할 수 없음). 되돌리려면 지금 CSV를 고치거나 DB 백업을 쓰세요.
  • CSV에 새로 더한 열은 키오스크 등록 화면에 입력 칸을 만들지 않습니다.
  • Polaris Office는 처음에 자기 앱의 파일 접근 권한을 묻습니다. 12.4인치 태블릿의 Microsoft Excel 편집은 Microsoft 365 구독이 필요할 수 있습니다.
  • 성을 따로 받기 전에 등록된 두 글자 이름은 성과 이름을 나눌 수 없어 이름 칸에 통째로 들어갑니다. CSV의 성 칸에 성을 적으면 나뉩니다.
  • 사용 설명서(docs/user-guide)의 등록 화면과 ‘○○ 맞아요?’ 설명은 아직 고치지 않았습니다.
  • 서버를 운영할 태블릿(지금은 Tab S7+가 서버와 키오스크를 함께 실행)에서 실제 예배 중 쓰는 모습은 아직 보지 못했습니다.

사용 방법

CSV로 한꺼번에 고치기

  1. 명단 탭의 ‘CSV 편집 열기’로 face_db.csv를 엽니다(또는 PC로 옮겨 엑셀로 고친 뒤 같은 이름으로 다시 넣습니다).
  2. 값, 머리글 이름, 열, 줄을 고치고 저장합니다. 명단에 ‘CSV 편집 대기 중’이 보입니다.
  3. 서버를 다시 시작하거나 개발자 화면 › 데이터 › ‘CSV 지금 반영’을 누릅니다. 결과 창에 바뀐 사람·지운 사람·열 이름이 나옵니다.

한 칸이나 열 이름만 고치기

  1. 명단 탭에서 칸을 길게 눌러 값을 고치거나, 머리글을 길게 눌러 열 이름을 바꿉니다.
  2. 저장하면 CSV와 키오스크에 바로 반영됩니다.

실수했을 때

  1. 개발자 화면 › 데이터 › DB 백업에서 시각을 보고 ‘되돌리기’를 누릅니다. ‘CSV 반영 전’ 백업이 그 직전 상태입니다.
