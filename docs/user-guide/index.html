ALLSTAR FAITH ID · 사용 안내서 · 앱 2.0 따뜻한 안내자 (2026-10-31 기준)

얼굴로 출석하고 이름표를 뽑는 교회 키오스크

Faith ID는 카메라 앞에 선 교인을 안내 캐릭터 빛이와 함께 알아보고, 이름표를 출력하면서 출석을 남깁니다. 명단과 출석부는 서버 태블릿의 Faith DB Server가 보관하고, 키오스크 여러 대가 같은 명단을 1초 안에 나눠 씁니다.

이 안내서의 표시: 교인 키오스크 앞에서 직접 운영자 키오스크를 설치·관리하는 봉사자 관리자 서버 앱에 로그인하는 담당자

처음 설치

서버를 켜고 키오스크를 연결합니다

서버 태블릿 한 대와 키오스크 태블릿이 같은 Wi-Fi에 있어야 합니다. 한 태블릿에서 서버와 키오스크를 함께 써도 됩니다.

앱 설치 운영자 #

서버 태블릿에는 Faith DB Server를, 키오스크 태블릿에는 Faith ID를 설치하고, 한 태블릿에서 함께 쓸 때는 둘 다 설치합니다.

  • Faith ID (키오스크): faith_id.apk. 얼굴 인식 모델이 들어 있어 크기가 큽니다.
  • Faith DB Server (서버): faith_db.apk.
  • 설치 파일은 프로젝트 폴더의 dist/에 있습니다. 서버 주소와 관리자 계정은 담당자가 따로 가진 운영 정보 문서를 보세요.
이전 버전 위에 덮어 설치해도 설정과 데이터는 그대로입니다. 그래도 설치 전에 /sdcard/faceDB 폴더를 PC에 복사해 두세요.

서버 시작과 현황 관리자 #

위치 Faith DB Server › 현황
  1. Faith DB Server를 열고 관리자 ID와 비밀번호로 로그인합니다. 처음 비밀번호 1234로 들어가면 새 비밀번호를 정하라고 안내합니다.
  2. 저장소 권한(모든 파일 접근)을 물으면 권한 화면 열기에서 허용합니다.
  3. 첫 화면 현황을 위에서부터 확인합니다. 1번 서버 켜기가 아직이면 서버 시작을 누릅니다.
  4. 2번 키오스크 연결에 허락을 기다리는 기기가 있으면 허락하기를 누릅니다. 3번은 명단 인원과 얼굴 사진 수, 4번은 예배 뒤 출석부 저장입니다.
  5. 오른쪽 보라색 칸에 지금까지 출석 인원과 분류별 막대가 보입니다. 처음에는 부서별이고, 분류: 부서 ▾를 눌러 학년이나 CSV의 다른 열로 바꿀 수 있습니다(고른 값은 기억합니다). 누가 왔는지 보기는 출석 탭으로 갑니다.
태블릿을 다시 켜면 서버도 다시 시작해야 합니다. 번거로우면 서버 설정에서 자동 시작을 켭니다. 서버 태블릿은 충전기에 꽂아 두세요. 배터리가 부족해 절전에 들어가면 키오스크가 서버에 닿지 못할 수 있습니다.

키오스크 연결과 허락 운영자 관리자 #

위치 Faith ID › 설정 › DB 서버 그리고 Faith DB Server › 키오스크
  1. 키오스크에서 Faith ID를 엽니다. 카메라 권한과 알림 권한을 물으면 허용합니다.
  2. 오른쪽 위 구석의 거의 보이지 않는 톱니를 1초 넘게 길게 눌러 설정을 엽니다(키오스크 설정). DB 서버 탭의 DB 서버 주소에 서버 앱 키오스크 탭 아래 새 키오스크 연결에 나온 주소를 입력하고 저장합니다.
  3. 키오스크에 서버 허락을 기다린다는 안내가 나옵니다.
  4. 서버 앱 키오스크 탭(또는 현황 2번)에 같은 기기가 허락 대기로 나타나면, 우리 교회 기기인지 확인하고 허락하기를 누릅니다. 모르는 기기는 거절합니다. 여러 대가 기다리면 대기 중 전체 허락이 나타납니다.
  5. 허락되면 키오스크가 명단 전체를 받고 바로 인식을 시작합니다. 80명 기준 1초 안쪽입니다.

한 태블릿에서 서버와 키오스크 함께 쓰기 운영자 #

서버 태블릿에서도 Faith ID를 키오스크로 쓸 수 있습니다. 서버 주소는 처음 값 http://127.0.0.1:18080 그대로 두면 됩니다.

  • Faith ID를 열면 알림 영역에 Faith ID 키오스크 · 서버와 동기화를 유지하고 있습니다가 표시됩니다. 서버 앱을 앞에 띄워 두어도 키오스크는 뒤에서 명단을 받고 출석을 보냅니다.
  • 서버 앱에서 일을 마치면 Faith ID로 돌아오세요. 모델과 명단을 다시 불러오지 않고 바로 인식 화면이 됩니다.
출석하기

빛이가 알아보고 안내합니다

카메라가 화면 전체에 보이고, 위쪽 말풍선의 빛이가 할 일을 하나씩 알려 줍니다. 버튼은 아래쪽에 반투명하게 떠 있습니다. 출석은 이름표 버튼을 누른 순간 기록되고, 프린터가 없거나 인쇄를 취소해도 출석은 남습니다.

안내하는 빛이 교인 #

빛이는 키오스크의 안내 캐릭터입니다. 몇 초마다 눈을 깜빡이고, 아무도 없을 때는 가끔 두리번거리거나 살짝 뛰어오릅니다. 상황마다 아래처럼 반응합니다.

상황빛이의 동작
이름을 찾았을 때살짝 점프
처음 보는 얼굴갸우뚱
닮은 얼굴이 여럿일 때갸우뚱하고 두리번
“나 아닌데?”로 다시 찾을 때움찔하고 두리번
얼굴 등록 시작, 별 하나를 모을 때마다끄덕 (등록 중에는 하얀 얼굴과 같은 쪽으로 고개를 돌림)
등록이 잘 안될 때갸우뚱
별 15개를 다 모았을 때, 등록을 저장했을 때콩콩 두 번 점프
이름을 적을 때끄덕
이름표가 나올 때살짝 점프하고 흔들흔들
서버를 기다릴 때졸린 눈
아무도 없을 때 (10초 남짓마다)두리번, 살짝 점프, 두 번 깜빡, 흔들흔들 중 하나

안내 대상을 설정 › 일반에서 어린이 또는 어른으로 고릅니다. 어린이는 반말과 별·꽃가루, 어른은 같은 빛이가 정중한 말투로 안내합니다(예: “반가워, 하늘아!” / “하늘 님, 환영합니다”). 부르는 이름은 설정 › 일반 › 이름에서 이름만 또는 성과 이름으로 고릅니다.

동작 표는 앱 코드의 한 곳(GuideGestures)에 모여 있어 개발자가 쉽게 바꿀 수 있습니다.

얼굴로 출석하고 이름표 받기 교인 #

  1. 화면 가운데 동그라미 안에 얼굴이 들어오도록 서서 앞을 바라봅니다.
  2. 빛이가 반가워, (이름)!이라고 하면 아래쪽 이름표 받기를 누릅니다.
  3. 다른 사람으로 알아봤다면 나 아닌데?를 누릅니다. 빛이가 이런, 다시 찾아볼게!라고 하고 2초쯤 기다렸다가 다시 알아봅니다. 그동안 동그라미 안에 그대로 서 있으면 됩니다.
  4. 이름표 카드가 내려오고, 이름표를 가져가라는 안내 뒤 몇 초 지나 처음 화면으로 돌아갑니다. 같은 날 여러 번 출석하면 첫 시각과 횟수가 함께 남습니다.

인식될 때마다 키오스크가 그날의 얼굴 모습을 조금씩 더 배워(자동 보정) 시간이 지날수록 잘 알아봅니다.

처음 오신 분 등록 (별 15개) 교인 #

  1. 등록되지 않은 얼굴이면 빛이가 처음 보는 얼굴이네! 우리 친구 할까?라고 묻습니다. 좋아, 등록할래!를 누릅니다.
  2. 얼굴 위에 귀가 달린 하얀 얼굴이 겹쳐 보입니다. 하얀 얼굴이 바라보는 쪽과 크기를 그대로 따라 하면 됩니다. 얼굴 선이 만나는 곳이 바라보는 방향이고, 빛이도 같은 쪽으로 고개를 돌립니다. 말풍선은 한 문장으로 알려 줍니다. 예: 왼쪽을 보면서 동그라미에 얼굴을 쏙 맞춰 줄래?
  3. 정면·왼쪽·오른쪽·위·아래 다섯 방향을 동그라미 세 크기로 모아 모두 별 15개입니다. 보통 크기 다섯 방향을 먼저, 이어서 가까이(큰 동그라미를 얼굴로 꽉 채우기), 마지막으로 한 걸음 뒤로(작은 동그라미에 쏙 들어가기) 차례로 권합니다.
  4. 자세가 맞으면 얼굴 둘레의 노란 고리가 차오르고, 다 차면 별 하나가 얼굴에서 오른쪽 아래 별 개수로 날아갑니다.
  5. 권하지 않은 자세라도 아직 모으지 않은 자세면, 3초 넘게 그대로 있을 때 그 별도 모읍니다(오, 그것도 좋아!). 3초가 되기 전에는 권하는 자세를 계속 안내합니다. 이 시간은 설정 › 등록에서 바꿉니다.
  6. 별 15개를 다 모으면 큰 별과 꽃가루로 축하합니다. 이어서 선생님이 성과 이름을 따로 적고, 부서와 학년은 아래 칩에서 고릅니다(없는 부서는 직접 입력). 다 됐어요를 누르면 저장됩니다.
  7. 빛이가 등록 완료! 반가워, 다온아!처럼 이름만 불러 인사합니다. 명단은 서버와 다른 키오스크에 1초 안에 전달됩니다.
3초 넘게 방향을 못 맞추면 하얀 얼굴이 고개 돌리는 시범을 보이고, 거리가 계속 맞지 않으면 발자국으로 앞이나 뒤를 알려 줍니다. 여러 사람이 함께 보이면 한 번에 한 친구만 등록할게!라고 안내합니다. 등록은 알아보지 못한 얼굴에서만 시작하므로, 끝난 뒤 이미 등록된 사람인지 다시 묻지 않습니다. 같은 이름이 있어도 괜찮습니다. 부서와 학년으로 구분합니다.

닮은 얼굴 중 고르기 교인 #

닮은 형제자매가 모두 등록되어 있어 누구인지 확실하지 않으면, 빛이가 어? 닮은 친구가 있네!라고 하며 후보 이름 버튼을 보여 줍니다. 내 이름을 누르면 인사가 나오고, 이름표 받기를 누릅니다. 아무도 아니면 둘 다 아니에요를 누르면, 빛이가 잠깐 기다렸다가 다시 찾아봅니다.

후보가 자주 나오면 운영자가 키오스크 설정 › 인식의 기준을 조정합니다.

등록 없이 이름표만 교인 #

방문객이나 얼굴 등록을 원하지 않는 분을 위한 기능입니다. 얼굴 데이터는 저장하지 않고, 출석부에는 명단 외로 남습니다.

  1. 처음 보는 얼굴 화면에서 오늘은 이름표만을 누릅니다.
  2. 이름표에 넣을 성과 이름을 적고 필요하면 부서와 학년을 고른 뒤 이름표 받기를 누릅니다.

처음 화면으로 교인 #

등록이나 입력을 그만두려면 왼쪽 위 둥근 화살표 버튼(처음으로)을 누릅니다. 이름표가 나온 뒤에는 몇 초 지나 저절로 처음 화면으로 돌아갑니다. 오른쪽 위 구석의 흐린 톱니는 운영자용 설정이라 짧게 눌러서는 아무 일도 일어나지 않습니다.

이름표 출력

프린터와 이름표 모양

모두 키오스크 설정에서 합니다. 설정은 키오스크마다 따로 저장됩니다.

프린터 연결 운영자 #

위치 Faith ID › 설정 › 인쇄
  • 이름표 출력: 끄면 버튼을 눌러도 인쇄하지 않고 출석만 기록합니다.
  • Android 기본 인쇄: 태블릿에 설치된 인쇄 서비스로 인쇄합니다. 누를 때마다 인쇄 화면이 열립니다.
  • Brother QL-820NWB (Bluetooth): 태블릿 설정에서 먼저 페어링한 뒤 페어링된 Brother 프린터 찾기로 고르고, Brother 장착 용지 읽기로 용지 크기를 맞춥니다.
  • Nemonic (Bluetooth): 프린터의 Bluetooth 주소를 입력합니다. 기본 용지는 Nemonic 72×50 mm입니다.
  • 출력 매수, 출력 제한 시간, 출력 뒤 처음 화면으로 돌아가는 시간도 여기서 정합니다.

이름표 모양 바꾸기 운영자 #

위치 Faith ID › 설정 › 출력 템플릿
  1. 교회 로고가 있는 배경을 쓰려면 이미지 불러오기로 그림을 고르고, 방향이 맞지 않으면 이미지 시계방향 90도 회전을 누릅니다.
  2. 글자 영역(점선)의 위치와 크기(px)로 이름이 들어갈 자리를 정합니다. 이름표는 1 mm에 8점으로 그려집니다.
  3. 넣을 줄 수(1~3줄)와 줄마다 내용(이름·부서·학년), 글자 크기, 위치 이동을 정합니다.
  4. 왼쪽 미리보기를 확인하고 저장합니다.
줄 간격 자동 맞춤을 켜 두면 긴 이름도 영역 안에서 줄여 겹치지 않게 놓습니다. 끄면 이전 버전처럼 고정 위치에 놓여 글자가 크면 겹칠 수 있습니다.
명단 관리

서버 앱의 명단 탭

여기서 고친 내용은 CSV 파일과 모든 키오스크에 1초 안에 반영됩니다. 얼굴 등록은 키오스크에서만 합니다.

찾기, 정렬, 고치기 관리자 #

위치 Faith DB Server › 명단
  1. 이름은 성 이름으로 띄어 보입니다(예: 이 하늘). 성을 따로 적지 않고 등록한 두 글자 이름처럼 나눌 수 없는 이름은 그대로 보입니다.
  2. 검색란에 이름이나 부서를 입력하거나, 분류 버튼(처음에는 부서)을 눌러 그 값만 봅니다.
  3. 표의 머리글을 누르면 그 순서로 정렬하고, 다시 누르면 거꾸로 정렬합니다.
  4. 줄을 누르면 그 자리에서 성, 이름, 부서, 학년 칸이 열립니다. 고치고 저장을 누릅니다. 성을 비우면 이름 칸이 그대로 전체 이름이 됩니다.
  5. 칸 하나만 고칠 때는 그 칸을 길게 누릅니다. 이름을 길게 누르면 성과 이름 두 칸으로 고치는 창이 뜹니다.

얼굴 사진 열은 그 사람의 얼굴 데이터 수, 오늘 열은 오늘 출석 여부입니다.

열 이름과 분류 관리자 #

위치 Faith DB Server › 명단 머리글
  • 열 이름 바꾸기: 머리글(부서, 학년 · 나이 등)을 길게 누르면 이름을 바꾸는 창이 뜹니다. 예를 들어 부서를 반으로 바꾸면 명단 머리글, CSV 머리글, 키오스크 입력 칸, 출석부 머리글이 함께 바뀝니다. 내용은 그대로입니다. 비우면 기본 설정값으로 돌아갑니다.
  • 열 숨기기: 같은 창의 열 숨기기. 다시 보이게 하려면 개발자 화면 › 설정 › 명단 열에서 켭니다.
  • 분류: 현황, 명단, 출석 탭의 분류: 부서 ▾를 누르면 부서 대신 학년이나 CSV에 더한 다른 열로 나눠 볼 수 있습니다. 탭마다 고른 값을 기억합니다.
  • CSV에 새로 더한 열(예: 메모)은 명단에 열로 나타나지만, 키오스크 등록 화면에 입력 칸을 만들지는 않습니다.

명단에서 지우기 관리자 #

줄을 열고 명단에서 지우기를 누르면 확인 창이 뜹니다. 지우면 모든 키오스크에서도 지워지고 되돌릴 수 없습니다. 이미 남은 출석 기록은 지워지지 않습니다.

CSV(엑셀)로 한꺼번에 고치기 관리자 #

위치 Faith DB Server › 명단 › CSV 편집 열기, 개발자 화면 › 데이터

명단은 데이터 폴더의 face_db.csv에 늘 최신으로 저장됩니다. 이름은 family_name(성)과 given_name(이름) 두 열로 나뉘어 있고, 맨 끝 person_key 열은 사람을 구분하는 번호라 고치지 않습니다.

  1. CSV 편집 열기를 누르면 태블릿의 문서 앱(Microsoft 365, Polaris Office 등)으로 파일이 열립니다. PC에서 고친 뒤 같은 이름으로 다시 넣어도 됩니다.
  2. 값, 머리글 이름, 열, 줄을 고치고 저장합니다. 명단에 CSV 편집 대기 중이 보이고, 그동안 서버는 그 파일을 덮어쓰지 않습니다.
  3. 서버를 다시 시작하거나 개발자 화면 › 데이터의 CSV 지금 반영을 누르면 반영됩니다. 반영하기 전에 얼굴 DB를 백업하고, 결과 창에 고친 사람·지운 사람·열 이름을 알려 줍니다.
CSV에서 한 일결과
칸 값을 바꿈그 사람의 그 값만 바뀝니다. 그동안 앱에서 고친 다른 값은 그대로입니다.
성·이름 칸을 바꿈이름 전체가 바뀝니다.
머리글 이름을 바꿈 (값은 그대로)열 이름만 바뀝니다 (명단·키오스크·출석부).
열을 더하거나 지움그 열이 생기거나 없어집니다. 성·이름 열을 지운 것은 무시합니다.
줄을 지움그 사람이 명단에서 지워집니다.
명단에 없는 줄을 더함얼굴이 없어 사람을 만들 수 없습니다. 결과 창에 알려 줍니다.
실수를 막는 장치: 파일이 없거나 줄이 하나도 없으면 아무도 지우지 않습니다. 한꺼번에 10명 넘게, 그리고 명단의 30% 넘게 빠지면 지우지 않고 경고합니다. 엑셀이 파일을 열어 둔 사이에 키오스크에서 등록한 사람은 지워지지 않습니다. 한국어 엑셀의 ‘CSV’와 ‘CSV UTF-8’ 저장 모두 읽습니다.

백업과 되돌리기 관리자 #

위치 Faith DB Server › 개발자 화면 › 데이터 › DB 백업
  • 서버가 얼굴 DB를 데이터 폴더의 backups에 저절로 복사합니다: 하루에 한 번(14개까지), 그리고 CSV를 반영하거나 되돌리기 직전(20개까지). 지금 백업으로 직접 만들 수도 있습니다.
  • 목록에서 시각과 종류(매일, CSV 반영 전, 되돌리기 전, 직접)를 보고 되돌리기를 누르면 그때의 명단·얼굴 사진·열 이름으로 돌아갑니다. 지금 상태도 먼저 백업합니다.
  • 모든 키오스크가 명단을 새로 받습니다. 출석 기록은 그대로입니다.
  • CSV를 잘못 반영했다면 CSV 반영 전 백업이 그 직전 상태입니다.
DB 다시 읽기는 백업 파일을 직접 바꿔 넣을 때 쓰는 고급 기능입니다. 보통은 위의 되돌리기를 쓰세요.
출석 기록

서버 앱의 출석 탭

출석은 키오스크에서 이름표 버튼을 누른 순간 서버로 보내집니다. 서버가 꺼져 있던 동안의 출석은 다시 연결되면 들어옵니다.

날짜별 출석 표 관리자 #

위치 Faith DB Server › 출석
  • ◀ 전날 오늘 다음날 ▶로 날짜를 옮깁니다.
  • 위쪽 버튼에 분류별(처음에는 부서) 출석 막대와 온 사람/명단 수가 나옵니다. 누르면 그것만 봅니다. 분류: 부서 ▾로 학년이나 다른 열로 바꿀 수 있습니다.
  • 모두 / 온 사람 / 아직 안 온 사람으로 나눠 보고, 이름으로 찾을 수 있습니다.
  • 표에는 출석 여부, 이름(성 이름), 분류 열, 학년, 처음 온 시각, 키오스크가 나옵니다. 머리글을 누르면 정렬합니다. 명단 외 출석에는 명단 외 표시가 붙습니다.

출석부 파일로 받기 관리자 #

  • 출석부 CSV 저장: 보고 있는 날짜의 출석부를 attendance_2026-10-31.csv 같은 이름으로 데이터 폴더에 저장합니다. 출석이 들어오거나 명단이 바뀔 때마다 오늘 출석부가 자동으로 갱신되고, 머리글은 열 이름을 따릅니다. 현황 4번 출석부 저장도 같은 일을 합니다.
  • 기간 내보내기: 최근 7일, 최근 4주, 이번 달, 지난 달, 최근 3개월 중 고르면 attendance_시작일_끝일.csv로 저장합니다.
  • USB로 PC에 연결해 faceDB 폴더에서 가져갑니다.
키오스크 관리

어떤 키오스크가 붙어 있나

서버 앱의 키오스크 탭입니다. 요청·허락·마지막 접속 시각을 표로 보려면 개발자 화면 › 키오스크를 씁니다.

키오스크 상태 보기 관리자 #

  • 키오스크마다 상태(연결됨, 오프라인, 허락 대기)와 기기 이름, ID, 마지막 접속이 나옵니다.
  • 키오스크가 오프라인이어도 인식과 출석은 계속됩니다. 다시 연결되면 모아 둔 출석을 보냅니다.

연결 끊기와 요청 거절 관리자 #

더 쓰지 않거나 잃어버린 기기는 연결 끊기를 누릅니다. 그 기기는 더 이상 명단을 받거나 출석을 보낼 수 없고, 다시 쓰려면 새로 허락해야 합니다. 허락을 기다리는 모르는 기기는 거절합니다.

서버 중지와 종료 관리자 #

위치 Faith DB Server › 개발자 화면 › 상태
  • 서버 중지: 서버만 멈춥니다. 백업 파일을 바꿀 때 씁니다. 멈춘 동안에는 서버 시작이 보입니다.
  • 서버 종료 (앱 닫기): 서버를 끄고 앱을 닫습니다.
  • 어느 쪽이든 키오스크는 오프라인으로 계속 동작하고, 서버를 다시 시작하면 10초 안쪽에 다시 연결됩니다.
  • 앱 위쪽의 로그아웃은 서버를 켠 채로 관리 화면만 잠급니다. 자리를 비울 때 누르세요.
설정과 보안

서버 설정과 키오스크 설정

인식과 등록 기준은 처음 값으로 시험을 마쳤습니다. 바꿀 이유가 분명할 때만 바꾸세요.

서버 개발자 화면과 로그 관리자 #

위치 Faith DB Server › 앱 이름 옆 “개발자 화면”

서버 앱의 모든 설정과 상태, 기록을 꾸밈없이 확인하는 화면입니다. 서버 앱으로를 누르면 돌아갑니다.

  • 상태: 실행 여부와 켠 시각, 키오스크 접속 주소, DB revision, 명단·얼굴 샘플·삭제 기록 수, 오늘 출석, 키오스크 수, 앱 버전. 서버 중지·시작·종료 버튼.
  • 설정: 서버 설정, 명단 열, config.yaml 내용(비밀번호는 가려짐).
  • 데이터: CSV 상태(DB와 같음 / 편집 대기 중), CSV 편집 열기·CSV 지금 반영·CSV 저장·DB 다시 읽기·출석부 저장·기간 내보내기 버튼, DB 백업 목록, 데이터 폴더의 파일과 크기.
  • 키오스크: 모든 키오스크의 상태, ID, 기기 이름, 요청·허락·마지막 접속 시각을 한 표로.
  • 로그: 서버 기록 전체. 서버·키오스크 연결·명단 변경·출석·오류로 나눠 보고 찾을 수 있습니다. 복사로 담당 개발자에게 보낼 수 있습니다.

서버 설정 관리자 #

위치 Faith DB Server › 개발자 화면 › 설정
  • 관리자 ID: 로그인 ID. 처음 값은 admin입니다.
  • 포트: 처음 값 18080. 바꾸면 모든 키오스크의 서버 주소도 바꿔야 합니다.
  • 데이터 폴더: 얼굴 DB와 출석부가 저장되는 곳. 처음 값 /sdcard/faceDB. 폴더 선택으로 고를 수 있습니다.
  • 사람별 최대 얼굴 샘플 수: 자동 보정으로 늘어나는 얼굴 데이터의 상한 (처음 값 100).
  • 앱 실행 시 로그인 없이 서버 자동 시작: 켜면 태블릿을 다시 켠 뒤 앱만 열어도 서버가 시작됩니다.
  • 명단 열: 모든 열의 이름과 보이기를 한 번에 바꿉니다. 열은 CSV를 따라가고, 값이 하나도 없는 열은 명단에서 빠집니다. 열 이름은 명단 머리글을 길게 눌러도 바꿀 수 있습니다.

저장하면, 포트·데이터 폴더·최대 샘플 수가 바뀐 경우 서버가 새 설정으로 다시 시작합니다. 되돌리기는 저장 전 값으로 돌립니다.

관리자 비밀번호 바꾸기 관리자 #

  1. 개발자 화면 › 설정에서 관리자 비밀번호 변경을 누릅니다.
  2. 새 비밀번호를 두 번 입력하고 변경합니다. 6자 이상이어야 하고 1234는 쓸 수 없습니다.
비밀번호는 문서나 단체 대화방에 적지 말고 담당자끼리 직접 전달하세요. 담당자가 바뀌면 비밀번호도 바꾸세요.

키오스크 설정 운영자 #

위치 Faith ID › 오른쪽 위 흐린 톱니를 1초 넘게 누르기

아이들이 실수로 열지 않도록 톱니는 거의 보이지 않고, 짧게 누르면 아무 반응이 없습니다. 길게 누르는 동안 톱니가 또렷해지고 설정이 열립니다. 키오스크 개발자 화면에서는 설정 버튼으로 엽니다. 일곱 개 탭이 있고, 인쇄와 출력 템플릿은 이름표 출력에서 설명합니다.

  • 일반: 안내 캐릭터 이름(빛이, 별이 등), 안내 대상(어린이/어른), 개발자 화면 보기, 운영 중 시스템 바 숨기기. 이름: 빛이가 부르는 이름(이름만 “하은아” / 성과 이름 “김하은아”), 이름표에 성·이름 넣기.
  • 안내 문구: 빛이의 말 바꾸기.
  • 인식: 인식 최소 유사도(처음 값 0.4, 높을수록 엄격), 1·2위 점수 차(0.1, 작으면 후보를 보여 줌), 후보 표시 개수, 카메라, 얼굴 동그라미의 크기·위치·바깥 어둡기.
