ALLSTAR FAITH ID · 사용 안내서 · 앱 2.0 (2026-10-30 기준)

얼굴로 출석하고 이름표를 뽑는 교회 키오스크

Faith ID는 카메라 앞에 선 교인을 알아보고 이름표를 출력하면서 출석을 남깁니다. 명단과 출석부는 서버 태블릿의 Faith DB Server가 보관하고, 키오스크 여러 대가 같은 명단을 1초 안에 나눠 씁니다.

이 안내서의 표시: 교인 키오스크 앞에서 직접 운영자 키오스크를 설치·관리하는 봉사자 관리자 서버 앱에 로그인하는 담당자

처음 설치

서버를 켜고 키오스크를 연결합니다

서버 태블릿 한 대와 키오스크 태블릿이 같은 Wi-Fi에 있어야 합니다. 한 태블릿에서 서버와 키오스크를 함께 써도 됩니다.

앱 설치 운영자 #

두 앱을 설치합니다. 서버 태블릿에는 Faith DB Server를, 키오스크 태블릿에는 Faith ID를 설치하고, 한 태블릿에서 함께 쓸 때는 둘 다 설치합니다.

  • Faith ID (키오스크): faith_id.apk, 약 253 MB. 얼굴 인식 모델이 들어 있습니다.
  • Faith DB Server (서버): faith_db.apk, 약 20 MB.
  • 파일 위치와 서버 주소, 관리자 계정은 담당자가 따로 가진 운영 정보 문서를 보세요.
이전 버전(1.0)을 쓰던 태블릿에 덮어 설치해도 설정과 데이터는 그대로 옮겨집니다. 그래도 설치 전에 /sdcard/FaceDB 폴더를 PC에 복사해 두세요.

서버 시작과 로그인 관리자 #

위치 Faith DB Server › 현황
  1. Faith DB Server를 열고 관리자 ID와 비밀번호로 로그인합니다. 처음 비밀번호 1234로 들어가면 새 비밀번호를 정하라고 안내합니다.
  2. 얼굴 DB와 출석부를 저장할 폴더 권한(모든 파일 접근)을 묻으면 권한 화면 열기에서 허용합니다.
  3. 서버 시작을 누릅니다. 위쪽 표시가 실행 중으로 바뀌고, 등록 인원과 데이터 폴더가 보입니다.
  4. 화면의 DB 서버 주소: http://…:18080을 적어 둡니다. 키오스크에 이 주소를 입력합니다.
태블릿을 다시 켜면 서버도 다시 시작해야 합니다. 매번 누르기 번거로우면 서버 설정에서 자동 시작을 켤 수 있습니다.

키오스크 연결과 승인 운영자 관리자 #

위치 Faith ID › 설정(톱니) › DB 서버 그리고 Faith DB Server › 현황 › 키오스크
  1. 키오스크에서 Faith ID를 엽니다. 카메라 권한과 알림 권한을 묻으면 허용합니다.
  2. 오른쪽 위 톱니 버튼을 눌러 설정을 열고 DB 서버 탭의 DB 서버 주소에 서버 화면에 나온 주소를 입력한 뒤 저장합니다.
  3. 키오스크 왼쪽 아래에 서버 승인 대기 중 (client-…)이 표시됩니다.
  4. 서버 앱 현황의 키오스크 목록에 같은 ID가 승인 대기로 나타나면, 우리 교회 기기인지 확인하고 승인을 누릅니다. 여러 대는 대기 중 전체 승인으로 한 번에 승인합니다.
  5. 승인되면 키오스크가 명단 전체를 받고 바로 인식을 시작합니다. 80명 기준 1초 안쪽입니다.

한 태블릿에서 서버와 키오스크 함께 쓰기 운영자 #

서버 태블릿에서도 Faith ID를 키오스크로 쓸 수 있습니다. 서버 주소는 처음 값 http://127.0.0.1:18080 그대로 두면 됩니다.

  • Faith ID를 열면 알림 영역에 Faith ID 키오스크 · 서버와 동기화를 유지하고 있습니다가 표시됩니다. 서버 앱을 앞에 띄워 두어도 키오스크는 뒤에서 명단을 받고 출석을 보냅니다.
  • 알림 권한을 거절했다면 알림만 보이지 않고 동기화는 계속됩니다. 태블릿 설정 › 애플리케이션 › Allstar Faith ID › 알림에서 다시 켤 수 있습니다.
  • 서버 앱에서 일을 마치면 Faith ID로 돌아오세요. 모델과 명단을 다시 불러오지 않고 바로 인식 화면이 됩니다.
출석하기

카메라 앞에 서면 알아봅니다

키오스크 화면 가운데 타원에 얼굴을 맞추면 됩니다. 출석은 이름표 출력 버튼을 누른 순간 기록되고, 프린터가 없거나 인쇄를 취소해도 출석은 남습니다.

얼굴로 출석하고 이름표 받기 교인 #

  1. 화면의 타원 안에 얼굴이 들어오도록 서서 앞을 바라봅니다.
  2. 반가워요 (이름)!이 나오면 오른쪽 아래 이름표 출력하기를 누릅니다.
  3. 이름표가 나오고 몇 초 뒤 처음 화면으로 돌아갑니다. 같은 날 여러 번 출석하면 첫 출석과 마지막 시각, 횟수가 함께 남습니다.

인식될 때마다 키오스크가 그날의 얼굴 모습을 조금씩 더 배워(자동 보정) 시간이 지날수록 잘 알아봅니다.

처음 오신 분 등록 교인 #

  1. 등록되지 않은 얼굴이면 얼굴이 등록되어 있지 않아요가 나옵니다. 등록 시작하기를 누릅니다.
  2. 화살표가 가리키는 쪽으로 천천히 얼굴을 돌립니다. 왼쪽, 오른쪽, 위, 아래 방향마다 3장씩 모두 12장을 모읍니다.
  3. 얼굴등록이 완료되었어요!가 나오면 이름, 부서, 학년을 입력하고 저장하기를 누릅니다.
  4. 저장된 명단은 서버와 다른 키오스크에 1초 안에 전달됩니다. 다음부터는 바로 인식됩니다.
같은 이름이 있어도 괜찮습니다. 부서와 학년으로 구분하고, 기존 분의 얼굴 데이터는 덮어쓰지 않습니다.

이미 등록된 분 확인 교인 #

이미 등록된 분이 다시 등록하려 하면, 얼굴을 모은 뒤 이미 등록된 분과 얼굴이 매우 비슷해요: (이름)을 보여 줍니다.

  • 본인이 맞아요: 새로 만들지 않고 그분으로 출석합니다. 방금 모은 얼굴 사진은 그분의 데이터에 더해져 다음부터 더 잘 알아봅니다. 이어서 이름표를 출력하면 됩니다.
  • 처음 등록이에요: 닮은 다른 사람이면 누릅니다. 새 사람으로 등록합니다.

비슷한 얼굴 중 고르기 교인 #

닮은 두 분(형제자매 등)이 모두 등록되어 있어 누구인지 확실하지 않으면, 유사한 얼굴이 있습니다. 이름을 선택해 주세요.와 함께 후보 이름 버튼이 나옵니다. 내 이름을 누르고 이름표 출력하기를 누릅니다.

후보가 자주 나오면 운영자가 키오스크 설정 › 인식의 기준을 조정합니다.

등록 없이 이름표만 교인 #

방문객이나 얼굴 등록을 원하지 않는 분을 위한 기능입니다. 얼굴 데이터는 저장하지 않고, 출석부에는 명단 외로 남습니다.

  1. 미등록 안내 화면에서 이름표만 출력하기를 누릅니다.
  2. 이름표에 넣을 이름(필요하면 부서, 학년)을 입력하고 출력합니다.

처음 화면으로 교인 #

등록이나 입력을 그만두려면 오른쪽 위 둥근 화살표 버튼(처음으로)을 누릅니다. 이름표를 출력한 뒤에는 몇 초 뒤 저절로 처음 화면으로 돌아갑니다. 바로 옆 톱니 버튼은 운영자용 설정입니다.

이름표 출력

프린터와 이름표 모양

모두 키오스크 설정에서 합니다. 설정은 키오스크마다 따로 저장됩니다.

프린터 연결 운영자 #

위치 Faith ID › 설정 › 인쇄
  • 이름표 출력: 끄면 출력 버튼을 눌러도 인쇄하지 않고 출석만 기록합니다.
  • 프린터 종류 · Android 기본 인쇄: 태블릿에 설치된 인쇄 서비스로 인쇄합니다. 누를 때마다 인쇄 화면이 열립니다.
  • Brother (Bluetooth): 먼저 태블릿 설정에서 프린터를 Bluetooth로 페어링한 뒤 페어링된 Brother 프린터 찾기로 고르고, Brother 장착 용지 읽기로 넣어 둔 용지 크기를 맞춥니다.
  • Nemonic (Bluetooth): 프린터의 Bluetooth 주소를 입력합니다. 기본 용지는 Nemonic 72×50 mm입니다.
  • 출력 매수, 출력 제한 시간, 출력 뒤 처음 화면으로 돌아가는 시간(기본 3초)도 여기서 정합니다.

이름표 모양 바꾸기 운영자 #

위치 Faith ID › 설정 › 출력 템플릿
  1. 교회 로고가 있는 배경을 쓰려면 이미지 불러오기로 그림을 고릅니다. 방향이 맞지 않으면 이미지 시계방향 90도 회전을 누릅니다.
  2. 글자 영역(점선)의 위치와 크기(px)를 바꿔 이름이 들어갈 자리를 정합니다. 이름표는 1 mm에 8점으로 그려집니다.
  3. 아래쪽에서 넣을 줄 수(1~3줄)와 줄마다 내용(이름·부서·학년), 글자 크기, 위치 이동을 정합니다.
  4. 왼쪽 미리보기를 확인하고 저장합니다.
줄 간격 자동 맞춤을 켜 두면 긴 이름도 영역 안에서 줄여 겹치지 않게 놓습니다. 이전 버전에서 직접 맞춘 모양은 그대로 유지됩니다.
명단 관리

서버 앱의 명단 탭

여기서 고친 내용은 모든 키오스크에 1초 안에 반영됩니다. 얼굴 등록은 키오스크에서만 합니다.

찾기와 고치기 관리자 #

위치 Faith DB Server › 명단
  1. 위쪽 검색란에 이름, 부서, 학년 중 아무거나 입력하면 목록이 좁혀집니다.
  2. 고칠 사람의 수정을 눌러 이름, 부서, 학년을 바꾸고 저장합니다.

목록 위 요약에 등록 인원과 동명이인 수가 나옵니다. 샘플 열은 그 사람의 얼굴 데이터 수(최대 100개)입니다.

명단에서 삭제 관리자 #

사람의 삭제를 누르면 확인 창이 뜹니다. 삭제하면 모든 키오스크에서도 지워지고 되돌릴 수 없습니다. 이미 남은 출석 기록은 지워지지 않습니다.

엑셀로 한꺼번에 고치기 관리자 #

  1. CSV 저장을 누르면 데이터 폴더에 face_db.csv가 만들어집니다.
  2. 이 파일을 엑셀로 열어 이름, 부서, 학년을 고치고 같은 이름으로 저장합니다. 맨 끝 열(사람 구분 번호)은 고치지 않습니다.
  3. CSV 편집 반영을 누르면 바뀐 사람 수를 알려 주고 모든 키오스크에 반영합니다.

백업에서 복원 (DB 다시 읽기) 관리자 #

  1. 현황 탭에서 서버를 중지합니다.
  2. 데이터 폴더(/sdcard/faceDB)의 face_meta.db를 백업 파일로 바꾸고, 같은 이름의 -wal, -shm 파일은 지웁니다.
  3. 서버를 시작하고 명단 탭의 DB 다시 읽기를 누릅니다.
  4. 모든 키오스크가 명단 전체를 새로 받습니다. 80명 기준 1초 안쪽입니다.
출석 기록

서버 앱의 출석 탭

출석은 키오스크에서 출력 버튼을 누른 순간 서버로 보내집니다. 서버가 꺼져 있던 동안의 출석은 다시 연결되면 들어옵니다.

날짜별 출석 보기 관리자 #

위치 Faith DB Server › 출석
  • ◂ 전날 다음날 ▸ 오늘로 날짜를 옮깁니다.
  • 요약 줄에 출석 인원 / 명단 인원, 명단 외 인원, 두 번 이상 체크인한 인원이 나옵니다.
  • 사람마다 출석 여부, 첫 출석과 마지막 시각, 횟수, 출석한 키오스크가 보입니다. 명단 외 출석은 이름 뒤에 (명단 외)가 붙습니다.

출석부 파일로 받기 관리자 #

  • 출석부 CSV 저장: 보고 있는 날짜의 출석부를 attendance_2026-10-30.csv 같은 이름으로 데이터 폴더에 저장합니다. 이 파일은 출석이 들어올 때마다 자동으로도 갱신됩니다.
  • 기간 내보내기: 최근 7일, 최근 4주, 이번 달, 지난 달, 최근 3개월 중 고르면 attendance_시작일_끝일.csv로 저장합니다.

어떤 키오스크가 붙어 있나

키오스크 상태 보기 관리자 #

  • 키오스크마다 상태 표시(연결됨, 오프라인, 승인 대기)와 ID, 기기 이름, 요청·승인·마지막 접속 시각이 나옵니다.
  • 키오스크가 오프라인이어도 인식과 출석은 계속됩니다. 다시 연결되면 모아 둔 출석을 보냅니다.

승인 해제 관리자 #

더 쓰지 않거나 잃어버린 기기는 목록에서 승인 해제를 누릅니다. 그 기기는 더 이상 명단을 받거나 출석을 보낼 수 없고, 다시 쓰려면 새로 승인해야 합니다.

서버 중지와 종료 관리자 #

  • 서버 중지 (현황 탭): 서버만 멈춥니다. 백업 파일을 바꿀 때 씁니다.
  • 서버 종료 (오른쪽 위): 서버를 끄고 앱을 닫습니다.
  • 어느 쪽이든 키오스크는 오프라인으로 계속 동작하고, 서버를 다시 시작하면 10초 안쪽에 다시 연결됩니다.
  • 로그아웃은 서버를 켠 채로 관리 화면만 잠급니다. 자리를 비울 때 누르세요.
설정과 보안

서버 설정과 키오스크 설정

인식과 등록 기준은 처음 값으로 시험을 마쳤습니다. 바꿀 이유가 분명할 때만 바꾸세요.

서버 설정 관리자 #

위치 Faith DB Server › 설정 (오른쪽 위)
  • 관리자 ID: 로그인 ID. 처음 값은 admin입니다.
  • 포트: 처음 값 18080. 바꾸면 모든 키오스크의 서버 주소도 바꿔야 합니다.
  • 데이터 폴더: 얼굴 DB와 출석부가 저장되는 곳. 처음 값 /sdcard/faceDB. 폴더 선택으로 고를 수 있습니다.
  • 사람별 최대 얼굴 샘플 수: 자동 보정으로 늘어나는 얼굴 데이터의 상한 (처음 값 100).
  • 앱 실행 시 로그인 없이 서버 자동 시작: 켜면 태블릿을 다시 켠 뒤 앱만 열어도 서버가 시작됩니다.

저장하면 서버가 새 설정으로 다시 시작합니다. 연결된 키오스크는 잠시 오프라인이 되었다가 다시 붙습니다.

관리자 비밀번호 바꾸기 관리자 #

  1. 서버 설정에서 관리자 비밀번호 변경을 누릅니다.
  2. 새 비밀번호를 두 번 입력하고 변경합니다. 6자 이상이어야 하고 1234는 쓸 수 없습니다.
비밀번호는 문서나 단체 대화방에 적지 말고 담당자끼리 직접 전달하세요. 담당자가 바뀌면 비밀번호도 바꾸세요.

키오스크 설정 운영자 #

위치 Faith ID › 오른쪽 위 톱니 버튼

여섯 개 탭으로 나뉩니다. 인쇄와 출력 템플릿은 이름표 출력에서 설명합니다.

  • 일반: 연결 상태 화면 켜기, 운영 중 상단·하단 시스템 바 숨기기, 화면 안내 문구 바꾸기. 문구의 {name}, {label}, {clientId}는 실제 이름, 이름(부서, 학년), 키오스크 ID로 바뀝니다.
  • 인식: 인식 최소 유사도(처음 값 0.4, 높을수록 엄격), 1·2위 점수 차(0.1, 작으면 후보를 보여 줌), 후보 표시 개수, 사용할 카메라(전면/후면).
  • 등록: 방향별 수집 장수(3), 이미 등록된 얼굴로 볼 유사도(0.45), 사람별 최대 샘플 수, 인식될 때 얼굴 샘플 자동 추가(자동 보정).
  • DB 서버: 현재 연결 상태, 서버와 동기화 켜기/끄기, 서버 주소, 재시도 간격과 연결 제한 시간, 이 키오스크의 ID와 기기 이름. 새 키오스크 ID 발급을 누르면 서버에서 다시 승인해야 합니다.
서버 주소를 바꿔 저장하면 키오스크가 새 서버에 바로 다시 연결합니다. 앱을 다시 켤 필요는 없습니다.

연결 상태 화면 운영자 #

위치 Faith ID › 설정 › 일반 › 개발자 화면 보기

문제가 있을 때 켜서 확인합니다. 서버 연결 상태와 주소, 키오스크가 가진 명단 인원, 아직 보내지 못한 변경·출석 건수, 마지막 출력 결과가 나옵니다. 지금 동기화로 바로 받기를 요청하고, 로그로 최근 기록을 봅니다. 확인이 끝나면 다시 끄세요.

문제 해결

이럴 때는

키오스크에 “서버 앱 실행 및 연동 후 사용해주세요”가 나옴서버 앱이 실행 중인지, 두 태블릿이 같은 Wi-Fi인지 확인하세요. 태블릿 IP는 공유기가 정하므로 바뀔 수 있습니다. 서버 현황 탭의 주소와 키오스크 설정 › DB 서버의 주소가 같은지 보세요.
“서버 승인 대기 중”에서 멈춤서버 앱 현황 탭에서 그 키오스크를 승인하세요. 목록에 없으면 키오스크 서버 주소를 다시 확인합니다.
서버를 다시 켠 뒤 잠시 오프라인키오스크는 재시도 간격을 조금씩 늘려 가며 다시 붙습니다. 보통 10초 안쪽입니다. 그동안의 출석은 연결 후 보내집니다.
인식이 잘 안 되거나 미등록으로 나옴타원 안에 얼굴 전체가 들어오도록 조금 가까이 오거나 멀어지세요. 역광(뒤에 창문)이면 키오스크 위치를 바꾸세요. 계속 안 되면 다시 등록하면 본인 확인 후 얼굴 데이터가 보강됩니다.
다른 사람으로 인식됨출력하지 말고 처음으로를 누르세요. 자주 그러면 운영자가 인식 최소 유사도를 조금 올립니다.
이름표가 안 나옴출석은 이미 기록되었습니다. 설정 › 인쇄에서 프린터 종류와 Bluetooth 연결을 확인하세요. 연결 상태 화면의 출력 줄에 마지막 출력 결과가 나옵니다.
“서버와 동기화를 유지하고 있습니다” 알림이 안 보임알림 권한을 거절한 경우입니다. 동기화는 계속됩니다. 태블릿 설정에서 Allstar Faith ID의 알림을 켜면 보입니다.
관리자 비밀번호를 잊음담당 개발자에게 문의하세요. 서버는 비밀번호를 암호화해 저장해서 화면이나 파일에서 확인할 수 없습니다.
